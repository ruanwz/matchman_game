# 火柴人对战游戏 (Matchman Combat Game)

一个基于HTML5 Canvas的2D横版火柴人对战游戏，支持多种游戏模式和武器系统。

## 功能特性

### 游戏场景
- 🌿 草原场景
- 🏜️ 沙漠场景
- 🌊 沼泽场景

### 武器系统
- 🔪 小刀（近战）
- ⚔️ 长剑（近战）
- 🔫 手枪（远程）
- 💥 加特林冲锋枪（远程）

### 游戏模式
- ⚔️ PvP对战模式（两人对打）
- 🤝 双人合作模式
- 🎮 闯关模式

### 敌人类型
- 👤 敌对火柴人
- 👾 怪兽
- 🚜 坦克

### 特殊功能
- 🚜 可驾驶坦克
- 🎨 橙色火柴人皮肤

## 操作说明

### 玩家1控制
- **移动**: WASD键
- **跳跃**: W键
- **攻击**: J键
- **切换武器**: K键
- **驾驶载具**: L键

### 玩家2控制
- **移动**: 方向键
- **跳跃**: ↑键
- **攻击**: 数字键1
- **切换武器**: 数字键2
- **驾驶载具**: 数字键3

## 部署

### Netlify部署
1. 连接你的GitHub仓库
2. 构建命令: `echo 'No build needed'`
3. 发布目录: `.`

### Railway部署
1. 连接你的GitHub仓库
2. 会自动检测并部署静态站点

## 本地运行

```bash
# 使用Python启动本地服务器
python3 -m http.server 8000

# 或使用Node.js
npx serve
```

然后访问 `http://localhost:8000`
